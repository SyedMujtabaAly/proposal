# Syed Mujtaba Aly — Portfolio

A responsive, dependency-free portfolio using HTML, CSS, and JavaScript. Dark charcoal, warm orange, interactive project details, and an illustrative automation workflow.

## Run locally

Requires Node.js. From this folder, run `npm start`, then open http://127.0.0.1:4173.

Run `npm run check` to check JavaScript syntax. Deploy the `dist` folder to any static web host.

## Edit

- `dist/index.html`: biography, stack, contact, and page structure.
- `dist/styles.css`: visual theme and responsive layouts. Theme colors live in `:root`.
- `dist/app.js`: project descriptions, preview concepts, dialogs, and workflow animation.

The only external assets are Google Fonts, with local fallback fonts. Contact links use the supplied LinkedIn URL. No email address, GitHub URL, live demos, employment history, or verified impact metrics were supplied, so none are invented. Project interface previews use clearly labeled illustrative data and are not screenshots of the user's actual systems. No backend is required; contact actions open LinkedIn.

The supplied navy-suit portrait appears in the hero; the developer-at-work image appears in About. Images were extracted directly from the supplied PDFs without facial retouching. The workflow demo remains alongside the About imagery. Image files are in `dist/images/`.
